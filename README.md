# 💻 E-Portfolio | ครูผู้สอนเทคโนโลยีและการเขียนโปรแกรม

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) สำหรับครูผู้สอนด้านวิทยาการคำนวณ เทคโนโลยี และการเขียนโปรแกรม พัฒนาด้วย HTML5, CSS3 และ JavaScript ในรูปแบบ Single-Page Application (ไฟล์เดียวจบ) พร้อมรองรับการเผยแพร่ผ่าน **GitHub Pages**

---

## ✨ คุณสมบัติหลัก (Features)

* **โครงสร้างครบถ้วน 4 ส่วนหลัก:**
  1. **หน้าแรก (Home):** แนะนำตัวตนแบบย่อ พร้อมปุ่มทางลัดไปยังผลงานและบัญชี GitHub
  2. **แนะนำตัว (About):** ประวัติการศึกษา ปรัชญาการสอน และทักษะด้านเทคโนโลยี
  3. **ผลงาน (Projects):** การ์ดแสดงผลงาน สื่อการสอน และโครงงาน พร้อมลิงก์ไปยังซอร์สโค้ด
  4. **กิจกรรม (Activities):** ไทม์ไลน์บันทึกการฝึกอบรม การเป็นวิทยากร และการแข่งขันทางวิชาการ
* **ดีไซน์ทันสมัย:** ใช้โทนสีน้ำเงิน-ขาว (Blue & White Theme) สบายตา อ่านง่าย พร้อมฟอนต์ **Prompt** ที่รองรับภาษาไทยอย่างสมบูรณ์
* **Responsive Design:** รองรับการแสดงผลทั้งบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ (มีเมนู Hamburger สำหรับมือถือ)
* **Zero Dependencies:** เขียนด้วย Pure HTML, CSS และ Vanilla JavaScript ไม่ต้องติดตั้ง Library หรือ Framework เพิ่มเติม
